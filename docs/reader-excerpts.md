# 小说摘录

编辑器工具栏的“小说摘录”用于插入可搜索、可复制的文字片段。普通引用保留现有 Markdown 风格。摘录以 Tiptap JSON 保存，不保存为截图，也不引入自定义 Markdown 指令。

## 参数

| 属性            | 含义                       | 取值与限制                                                                                                              |
| --------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `variant`       | 阅读模板及来源平台         | 支持 `fanqie`（番茄轻小说）、`qidian`（起点读书）、`sfacg`（菠萝包轻小说）、`ciweimao`（刺猬猫阅读），默认使用 `fanqie` |
| `bookTitle`     | 小说书名                   | 最多 300 字；新建摘录时必填                                                                                             |
| `chapterTitle`  | 完整章节编号与标题         | 最多 300 字；可选                                                                                                       |
| `author`        | 作者                       | 最多 200 字；可选                                                                                                       |
| `sourceUrl`     | 原文链接                   | 表单接受可选的 HTTP(S) 链接，最多 2048 字符                                                                             |
| `readerTime`    | 创建时间                   | 插入时读取设备本地时间，格式为 `HH:mm`；保存后不因阅读或编辑重新生成                                                    |
| `batteryLevel`  | 阅读页显示的电量百分比     | 0 至 100 的整数；新建表单番茄默认 100，起点、菠萝包和刺猬猫默认 75；缺省历史属性的兼容值仍为 100                        |
| `pageLabel`     | 兼容旧数据的页码           | 仅保留旧数据读取兼容；新摘录保存 `1/1`，实际显示使用运行时分页状态                                                      |
| `progressLabel` | 兼容旧数据的阅读进度       | 新摘录保存空值，不提供手动输入                                                                                          |
| `headerLabel`   | 金币或热评区域的自定义文字 | 最多 80 字；番茄和起点留空时使用平台默认文字；菠萝包和刺猬猫隐藏顶部信息字段及其展示，但保留已有自定义值                |
| `content`       | 摘录正文                   | 标准块节点；表单将每个非空文本行转换为一个段落                                                                          |

```ts
editor.commands.insertNovelExcerpt(
  {
    variant: "fanqie",
    bookTitle: "小说书名",
    chapterTitle: "第2章 章节标题",
    author: "作者名称",
    sourceUrl: "https://example.com/chapter",
    // 省略 readerTime，插入命令会记录设备本地的创建时间。
    batteryLevel: 100,
    headerLabel: "00:24得991金币",
  },
  [
    { type: "paragraph", content: [{ type: "text", text: "第一段摘录正文。" }] },
    { type: "paragraph", content: [{ type: "text", text: "第二段摘录正文。" }] },
  ],
);
```

## 展示与交互

宿主应用需要加载 `@ricetext/editor-core/styles.css`。四种平台模板共用文字正文、来源链接和分页控制器，并保留各自阅读页的展示：

| 模板                  | 纸面与正文                                 | 顶部与章节                                 | 页脚                                                                                     |
| --------------------- | ------------------------------------------ | ------------------------------------------ | ---------------------------------------------------------------------------------------- |
| 番茄轻小说 `fanqie`   | 暖色纸面、宋体风格                         | 书名在章节上方，保留金币提示与箭头         | 左侧实际页码，右侧创建时间和电量                                                         |
| 起点读书 `qidian`     | 浅灰纸面、楷体风格、段尾空气泡             | 书名在章节上方，保留热评文字               | 左侧实际页码与整数百分比，右侧创建时间和电量                                             |
| 菠萝包轻小说 `sfacg`  | 灰色纸面、楷体风格、段尾空气泡             | 章节居中，右上月亮装饰；书名从顶部移至页尾 | 左侧电量在前、创建时间在后；右侧书名及整数百分比；实际页码视觉隐藏并保留可访问的更新提示 |
| 刺猬猫阅读 `ciweimao` | 浅色纸面、无衬线正文、右侧细轨道及段尾圆点 | 书名在章节上方，章节不显示返回箭头         | 左侧实际页码及两位小数百分比，中间“开启弹幕”装饰，右侧创建时间和电量                     |

书名自动加书名号，只渲染一份；菠萝包页脚的长书名在剩余宽度内省略，其完整文字与来源链接仍保留。其他模板书名使用接近章节标题且颜色略深的样式。提供来源链接时，直接点击书名打开原文，悬停、聚焦和按下时均不显示下划线，也不再显示单独的来源脚注。顶部设备状态栏不渲染。

电量仍是可配置的显示参数，不代表当前设备的真实电量。时间记录摘录创建时的本地时间，不是持续走动的时钟。正文始终为可选择的文字，不使用截图背景。桌面与手机上的摘录正文字号均继承外层文章或编辑器正文的字号，同时保留平台各自的字体和行距。字体使用已打包或本机可用字体，不同系统的字形可能略有差异。

新建对话框打开时记录一次本地 `HH:mm` 时间用于稳定预览，点击插入时再记录实际生成时间。重新打开新建表单会获得新的预览时间。已有摘录在修改来源、切换模板、保存和刷新后保留原始时间；缺少时间的历史数据不会在读取时伪造时间。表单不提供手动填写时间、页码或进度的字段。

## 分页

四模板均由同一分页控制器按实际内容和可用尺寸计算当前页与总页数。桌面完整显示正文，页码始终为 `1/1`。手机上的只读预览和阅读页动态分页，页数和翻页位置不作为文档修改持久化。编辑状态保持正文连续展开和 `1/1`，避免翻页手势干扰输入与选择。旧的页码、进度属性仍可读取，但不控制实际分页显示。

实际进度为“当前页序号 ÷ 总页数 × 100%”（当前页序号从 1 开始）。起点和菠萝包显示四舍五入的整数百分比，刺猬猫固定显示两位小数；例如第 1 页、共 3 页时分别显示 `33%`、`33%` 和 `33.33%`，单页或末页分别显示 `100%`、`100%` 和 `100.00%`。番茄仅显示页码。菠萝包保留 `.rt-reader-progress` 的实际页码更新供辅助技术读取，但视觉上仅在页脚展示书名和百分比。翻页、字体加载和视口变化后，页码与百分比都随实际分页状态更新，不使用参考图上的固定数字。

分页控制器位于 `packages/editor-core/src/use-reader-pagination.ts`，尺寸计算及重新排版的纯函数位于 `reader-pagination.ts`，有边界约束的 `ReaderPageState` 位于文档核心包。分页使用浏览器原生 CSS 分栏，不改写原始文档。点击只读正文左半区域翻到上一页，右半区域翻到下一页；正文获得键盘焦点后，可使用 ArrowLeft、ArrowRight、Home 和 End。选字、长按、拖动、点击标题链接或底栏不会触发翻页。

字体加载、内容变化和视口缩放会重新计算布局；分栏宽度保留小数精度，避免翻页后累计偏移并裁切文字。从桌面切回手机时保留近似阅读位置。不含交互控制器的纯 HTML 导出会回退为单页完整正文。

新建表单提供番茄、起点、菠萝包和刺猬猫四个模板。切换平台只会更新尚未修改的可配置默认值：番茄默认显示 100% 电量，其余三种默认显示 75%。已自定义的电量、顶部文字以及已有摘录信息都会保留。番茄和起点的空 `headerLabel` 分别使用“00:24得991金币”和“起点热评”，不会伪造评论数量。菠萝包和刺猬猫不显示“顶部信息”输入框或旧金币、热评提示，切回番茄或起点仍保留原有自定义文字。金币提示与箭头保持单行，过长的自定义提示省略显示，并可悬停查看完整文字。

将光标放在已有摘录内，再打开“小说摘录”，即可修改来源和模板。已有富文本正文不会被重建，可在编辑器中直接修改；操作支持撤销和重做。取消对话框会放弃未提交的表单修改。

## 兼容性

旧数据中的 `desktop-book`、`mobile-book`、`forum-evidence`，以及未知或缺省模板值，统一归一化为 `fanqie`。这只是读取、插入、编辑或保存时的兼容处理，不执行全库迁移，也不删除用户数据。原有正文、书名、章节、作者和安全来源链接仍保留，但不再提供旧模板的专用样式或渲染行为。HTML 序列化保留来源元数据，并为正文提供独立的 `.rt-novel-excerpt__content` 容器。解析时只读取该容器中的正文，同时兼容旧版直接包含段落的 `aside`，避免标题和来源链接重复进入正文。共享文档边界仍会净化来源链接。

平台和来源信息由用户填写，不表示系统已核验其真实性。粘贴到摘录表单的纯文本不会被解释为 HTML 或 Markdown。书名、章节和正文均为实际文字；已移除的顶部通知图标不再保留图片依赖，底部电池也不依赖图片资源。

起点、菠萝包和刺猬猫的共享平台策略均为 `emptyBubble=true`：起点显示段尾空轮廓，菠萝包显示段尾气泡装饰，刺猬猫显示段尾圆点及右侧细轨道；番茄不自动添加空气泡。气泡、圆点和细轨道不包含伪造的评论、回复或阅读数量，也不提供评论入口。菠萝包的月亮和刺猬猫的“开启弹幕”及箭头设置 `aria-hidden`，不充当按钮、链接或键盘焦点，不会开启弹幕、切换主题或触发翻页。正文区域原有翻页手势仍由分页控制器处理。实际论坛间帖标记不会混入四种阅读模板。
